# Customer Churn Prediction & Retention Analytics

**Machine Learning + Data Analytics | Python, Scikit-learn, Pandas, SQL**

All data is **SYNTHETIC** — generated by `train.py` (seed 42, 4,500 customers). No real customer data.

## What it does
EDA, Gradient Boosting classifier, 5-fold cross-validation, test evaluation, feature importances, and retention segment analysis (month-to-month, low-tenure customers are the high-risk segment).

## Run
```bash
pip install -r requirements.txt
python train.py
```

## Results (actual run output)
- Rows: **4,500** | Churn rate: **0.1647**
- Cross-validated ROC-AUC: **0.7822** | Test ROC-AUC: **0.8122**
- Precision: **0.4750** | Recall: **0.1284** | F1: **0.2021**
- Feature importances: contract_type 0.3140, tenure_months 0.2721, monthly_charges 0.2212, total_charges 0.1581, tech_support 0.0261, online_security 0.0085
- Top feature: **contract_type**. Note: recall is low at the default 0.5 threshold — threshold tuning for retention campaigns is the documented next step.
